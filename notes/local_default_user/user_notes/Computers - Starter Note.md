# Computers

## Starter focus
- Programming systems and language fundamentals
- Data structures and algorithms
- Artificial intelligence foundations

## Seed books
- A Tour of C++, Third Edition
- Advanced Data Structures
- Artificial Intelligence: A Modern Approach

## 1-week action plan
### Day 1 — Map the area
- Review the three seed books and identify what each is best for.
- Write 3-5 questions you want this collection to answer.
- Decide a primary focus for this week: programming, data structures, or AI foundations.

### Day 2 — C++ fundamentals
- Read one short section from *A Tour of C++, Third Edition*.
- Note key ideas: types, functions, classes, and modern C++ style.
- Capture one note with examples relevant to your own projects.

### Day 3 — Data structures pass
- Read one introductory section from *Advanced Data Structures*.
- Summarize the difference between basic and advanced structures.
- List 2-3 structures you want to understand deeply.

### Day 4 — AI foundations pass
- Read one introductory section from *Artificial Intelligence: A Modern Approach*.
- Note the main AI problem areas covered in the book.
- Write a short reflection on which AI topics connect to robotics or embedded systems.

### Day 5 — Compare and connect
- Compare the three books by difficulty, usefulness, and relevance.
- Decide which one should be your main book and which should stay as references.
- Add links or follow-up notes for overlapping topics.

### Day 6 — Build a mini study structure
- Create subtopics you want to grow this collection around: systems, software engineering, algorithms, AI, theory.
- Add at least 2 more books or notes if needed.
- Organize open questions you want to revisit next week.

### Day 7 — Review and next-step decision
- Review all notes from the week.
- Write a short summary: what you learned, what felt hard, and what to study next.
- Pick one concrete reading target for next week.

## Next steps
- Add more books by subtopic: systems, software engineering, AI, theory
- Add notes while reading and link them back to sources
