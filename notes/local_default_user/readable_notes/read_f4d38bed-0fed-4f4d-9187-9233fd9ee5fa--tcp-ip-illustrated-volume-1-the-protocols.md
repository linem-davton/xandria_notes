# Chapter 1 Introduction

## 1.2.2 Multiplexing, Demultiplexing, and Encapsulation in Layered Implementations

<!-- xandria:highlight:start {"version":1,"sourceReadableId":"read_f4d38bed-0fed-4f4d-9187-9233fd9ee5fa","annotationId":"ann_12da0251-2e98-44f5-9167-e7ff5b5700d4","sourceUpdatedAt":"2026-04-27T21:34:32.687Z"} -->
Different network devices implement different subsets of the protocol stack. End hosts tend to implement all the layers. Routers implement layers below the transport layer, and switches imple￾ment link-layer protocols and below. This idealized structure is often violated because routers and switches usually include the ability to act as a host \(e.g., to be managed and set up\) and therefore need an implementation of all of the layers even if they are rarely used.
